Adds a Heraldry Table for designing custom sail patterns for [Small Ships](https://modrinth.com/mod/small-ships).

Paint and print a pattern, then install, replace, or remove it directly on a ship's sails.

Printed patterns can be duplicated with paper.

Also supports sail ships from [Small Ships Addon](https://www.curseforge.com/minecraft/mc-mods/small-ships-addon) and [Small Ships Viking Addon](https://www.curseforge.com/minecraft/mc-mods/small-ships-viking-addon) when installed.
